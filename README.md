# Mahakal Mobile Hub

Professional Android app for mobile shop.

## Features
- Clean modern UI
- Categories: Smartphones, Refurbished, Repair, Accessories
- Indore: 2-hour delivery + COD
- All India: Prepaid only
- WhatsApp enquiry button
- Easy to update via GitHub (photos, prices, offers)

## How to build APK
1. Push code to GitHub
2. Go to Actions tab
3. Run "Build APK" workflow
4. Download APK from Artifacts
